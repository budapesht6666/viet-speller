# Viet Speller

Вьетнамский с нуля для тех, кто уже живёт во Вьетнаме. Говорить начинаешь
с первого урока, а учишь то, что пригодится завтра: рынок, кафе, Grab, пиклбол,
ремонт в квартире, врач, банк.

Интерфейс на русском. Приложение открывается в браузере телефона и ставится
на домашний экран.

> Статус: работают уроки алфавита, тонов и цифр, тренировка, разговорник,
> семья с рейтингом и ачивки. Что сделано по этапам — `PLAN.md`, «Состояние».
> Выкатка — `deploy/README.md`.

## Как устроено обучение

- **Путь по темам**, как в Duolingo: основы (алфавит, тоны, цифры,
  вежливость) → город → быт → учреждения → досуг. Следующая тема открывается
  после первого уровня предыдущей.
- **Короткие уроки по 3–5 минут**, как в Falou. Слушаешь фразу и повторяешь.
  Видишь русский и говоришь сам. Угадываешь на слух, собираешь фразу из слов,
  проигрываешь мини-диалог.
- **Проверка произношения** — распознаванием речи в браузере, сразу после
  сказанного.
- **Четыре уровня темы**: «Узнаю» → «Повторяю» → «Говорю сам» → «Свободно».
- **Повторение** по алгоритму FSRS: каждый день собирается тренировка из
  того, что пора освежить.
- **Ачивки и семья.** Общая семья, недельный рейтинг по минутам практики,
  семейные цели.
- **Разговорник «показать».** Всё выученное можно вывести крупно на экран
  и включить озвучку: не получилось сказать — покажи. Работает без сети.
- **Режим «не могу говорить»** для автобуса и очереди: упражнения только
  на слух и касания.

## Про выговор

Образцы озвучены нейросетевыми голосами со стандартным выговором: голосов
с центральным выговором нет ни у одного сервиса. Где Юг, Север и Центр
говорят по-разному, у слова есть пометка. Говору Центра (`mô`, `tê`, `răng`,
`rứa`) отведён отдельный модуль на понимание на слух — чтобы понимать соседей
в Дананге и Хойане.

## Что нужно для работы

- Интернет: распознавание речи идёт на серверах Apple или Google. Без сети
  работает только разговорник.
- HTTPS: по http браузер не даёт доступ к микрофону.
- Разрешение на микрофон. Без него остаются упражнения на слух.

## Технологии

| Часть | Что |
|---|---|
| Клиент | Vite, TypeScript, Preact, GSAP, PWA |
| Сервер | NestJS, Prisma, SQLite |
| Распознавание | Web Speech API (`vi-VN`), сравнение по Левенштейну |
| Повторение | FSRS (`ts-fsrs`) |
| Озвучка | заранее сгенерированные файлы: edge-tts / ElevenLabs |
| Иконки | [Streamline](https://www.streamlinehq.com) free, CC BY 4.0 |

Ядро (матчер, распознавание, звук, дизайн-система) взято из
[Speller](https://github.com/budapesht6666/speller), там же журналы замеров
распознавания на iPhone.

## Разработка

Нужен Node 24.15 или новее (`.nvmrc`) и Python-пакет `edge-tts` для озвучки.

```powershell
npm install
copy apps\api\.env.example apps\api\.env

npm run dev        # клиент на http://localhost:5180
npm run dev:api    # сервер на http://localhost:3000, клиент ходит к нему через прокси
npm test           # все тесты; их же запускает pre-commit
npm run build      # пакеты, клиент, сервер
```

Собранный сервер раздаёт и клиент: `npm run build`, затем
`node dist/main.js` в `apps/api` — приложение на http://localhost:3000.

Стенд дизайн-системы — `/design-system.html`.

### На телефоне

Распознаванию нужен https, поэтому дев-сервер выставляется наружу туннелем:

```powershell
npm run dev
npm run tunnel     # выдаст https://….trycloudflare.com
```

Адрес туннеля после перезапуска меняется, и ярлык на домашнем экране
приходится ставить заново.

### Замер распознавания (этап 0)

```powershell
npm run probe:phone    # проба и https-туннель, адрес и QR-код для телефона
```

Протокол — [research/VI-PROBE-CHECKLIST.md](research/VI-PROBE-CHECKLIST.md).

### Озвучка и иконки

Файлы коммитятся, заново их обычно генерировать не нужно.
`npm run tts:probe` — образцы для пробы (edge-tts), `npm run assets` — иконки
Streamline, `npm run icons -w @viet/web` — иконки PWA из `icon.svg`.
