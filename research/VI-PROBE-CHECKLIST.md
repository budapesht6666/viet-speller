# Протокол замера vi-VN

Этап 0 из `PLAN.md`. Все факты о распознавании в Speller сняты на `en-US`;
здесь проверяем, какие из них верны для вьетнамского и какие упражнения
вообще возможны. До замера код уроков не пишем.

## Один раз — iPhone

1. **Настройки → Основные → Клавиатура → «Включить диктовку».**
   Выключенная диктовка глушит распознавание молча.
2. Там же **Клавиатуры → Новые клавиатуры → Вьетнамская → Telex — QWERTY.**
   Нужна ли она — не измерено; в прогоне A она была добавлена.

## Автозамер

На ноутбуке:

```powershell
npm run probe:phone
```

Команда поднимает сервер пробы и https-туннель к нему (без https iPhone не
даёт микрофон) и печатает QR-код. Образцы играет сам сервер колонками
ноутбука через ffplay — браузер на ноутбуке не нужен. Громкость средняя,
без наушников.

На iPhone:

1. Камерой на QR-код → открыть в Safari. Не открылось — подождать 10–20 с и
   обновить: новый адрес расходится по DNS не мгновенно.
2. **«Начать автозамер»**, разрешить микрофон.
3. Положить телефон примерно в метре от ноутбука и ничего не трогать
   ~2–5 минут.

Дальше всё само: на каждое задание новая сессия распознавания, ноутбук
играет образец, окно закрывается через 1.5 с после финала или через 12 с
тишины, следующее задание. Отчёт сохраняется на ноутбуке в `research/runs/`.

Касание нужно ровно одно: без жеста Safari не даёт микрофон. Если Safari
не даст начать следующую сессию без касания, автозамер остановится и
скажет об этом — это тоже результат.

Окно терминала не закрывать до конца: адрес туннеля при каждом запуске новый.

## Ручной режим

Спойлер «Ручной режим» на странице. Там же переключатели:

| «Кто говорит» | Что делать |
|---|---|
| образец с другого устройства | «Слушать» — ноутбук сыграет образец сам |
| я сам | сказать текст с экрана; перед этим можно нажать «Образец» и повторить |
| носитель языка | попросить соседа или хозяина квартиры прочитать с экрана |
| образец с этого же телефона | «Слушать», потом «Образец» на том же телефоне: слышит ли телефон свой динамик |

«Сессия распознавания»: по умолчанию **новая на каждое задание**. В прогоне
A одна сессия на весь замер оборвалась сама через ~60 с, а перезапущенная
пришла с мёртвым микрофоном (`VI-PROBE-RESULTS.md`). «Одна на весь замер»
оставлена, чтобы этот обрыв повторить.

Строка «Телефон слышит сейчас» показывает всё, что доходит до
распознавания, даже вне окна. Пустая, пока играет образец, — телефон не
слышит колонку: громче или ближе.

В конце — «Сохранить отчёт на ноутбук». Нет связи с ноутбуком — отчёт
копируется в буфер, его можно прислать в чат.

## Как читать отчёт

| Строка отчёта | Если да | Если нет |
|---|---|---|
| **interim / финал**: первый interim приходит за доли секунды | Проверка по interim, как в Speller | Упражнения ждут финала, в интерфейсе явное «слушаю…» |
| **диакритика**: есть почти во всех ответах | Сравнение с тонами возможно | Тон по распознаванию не проверить — только упражнения на слух |
| **неверный тон**: «как сказано» | Подсказка «слово верно, тон другой» честна | Движок исправляет тон по смыслу. Пишем в README: тон проверяет только ухо |
| **шесть тонов ma**: тон совпал у большинства | Тренировка тонов голосом | Тоны — только на слух |
| **одиночный слог** узнан | Алфавит и тоны голосом | Отдельные звуки только на слух, голосом — в составе слова |
| **числа** цифрами | В профиль `vi` нужна свёртка «цифры ↔ слова» | Числа сравниваются как слова |
| **фразы** целиком | Упражнение «скажи фразу» | Фраза проверяется по частям |

Кроме сводки из журнала выписываем: `onresult len=… idx=…` (копит ли
движок всё в одном результате), `alts=` и confidence, `SR onend` с временем
жизни сессии, ошибки `SR ONERROR` кроме `no-speech` и `aborted`.
