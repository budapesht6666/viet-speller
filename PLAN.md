# План: Viet Speller — вьетнамский с нуля, живя во Вьетнаме

## Контекст

Семья живёт в Центральном Вьетнаме (Дананг, Хойан, Нячанг) и учит вьетнамский
с нуля. Занимаются взрослые и подростки. Цель не экзамен, а жизнь: рынок,
пиклбол, кафе, Grab, ремонт в квартире, запись к врачу, банк.

Механику берём у Falou: говорить с первого урока, короткие уроки вокруг
бытовых ситуаций, мгновенная проверка произношения, повторение по карточкам.
Структуру пути берём у Duolingo: темы идут друг за другом, у каждой есть
уровни, ачивки и ежедневная цель.

Технический предок — Speller (`lang-game_research`, `github.com/budapesht6666/speller`).
Оттуда берём измеренные факты о распознавании, матчер, захват микрофона, звук,
дизайн-систему на токенах и скрипт ассетов. Падающие предметы не берём.

**Язык интерфейса — только русский. Язык обучения — только вьетнамский.**
Слоя i18n нет. Строки интерфейса всё равно лежат в одном файле, чтобы не
искать их по разметке.

## Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Выговор | Стандартное письмо и лексика, у расходящихся слов пометка «на Юге / на Севере / в Центре говорят…». Отдельный модуль на понимание говора Центра (mô, tê, răng, rứa, ni) | Голоса TTS с центральным выговором нет ни у кого. Учить по образцу, которого нет, нельзя, а понимать соседей на рынке надо |
| Кто учится | Взрослые и подростки 12+ | Детского режима «без чтения» нет, взрослые темы (банк, врач) есть |
| Прогресс | У каждого свой телефон, прогресс на сервере, общая семья, семейный рейтинг | Без сервера нет ни рейтинга, ни восстановления после переустановки |
| Бэкенд | NestJS, заодно как учебный проект | Пожелание владельца. Код бэкенда пишется «по учебнику Nest», без самодельных обходов |
| База | SQLite через Prisma, файл в `data/` | По `vps-ops` состояние живёт в `/srv/apps/<app>/data` и попадает в ночной бэкап само. Postgres стоил бы 200 МБ памяти и отдельного дампа ради семьи из нескольких человек |
| Проверка контента | Как в Speller: сомнительный перевод не вносим вовсе; синонимы через `alt`; полноту и связность проверяют тесты | Неверное слово игра закрепит молча, и человек об этом не узнает |
| Озвучка | Файлы генерируются скриптом при подготовке контента и коммитятся. Кандидаты: edge-tts (vi-VN, бесплатно, без лимита) и ElevenLabs (бесплатная квота ~10 тыс. символов в месяц). Выбор голоса — слепым прослушиванием | Тон ловят на слух, и системный голос, разный на каждом телефоне, учит разному тону |
| ИИ-собеседник | Только на бесплатном тарифе, последним этапом, по желанию | Платный вариант не рассматривается |
| Доп. механика | Разговорник «показать собеседнику», работает офлайн | Не можешь сказать, так покажи врачу или мастеру |
| Аркада | Падающих предметов нет | Решение владельца |
| Фронтенд | Vite + TypeScript + Preact с `@preact/signals` | В Speller было три экрана, здесь их больше десяти, а у урока сложное состояние. На голом DOM это превращается в самописный фреймворк. Preact весит 4 КБ и не мешает GSAP |
| Повторение | FSRS через `ts-fsrs` | Современный алгоритм интервалов, MIT. Самим писать SM-2 смысла нет |
| TypeScript | 6.0 во всём монорепо, не 7 | Nest CLI 12 зависит от `typescript ~6.0`, у `@nestjs/swagger` в peer-зависимостях `^5 \|\| ^6`. Одна версия на весь репозиторий, иначе клиент и сервер проверяют `packages/core` по-разному |
| Prisma | 7.10, не `latest` | Тег `latest` в npm в октябре 2026 указывает на 8.0 RC. Учебному проекту нужна стабильная версия, по которой написана документация |
| Локальная база клиента | `idb` (обёртка над IndexedDB, ~1 КБ) | Журнал событий и очередь отправки — это две таблицы и индекс. Dexie с живыми запросами весит в десятки раз больше и здесь не нужен |
| Числа словами | `read-vietnamese-number` (MIT, без зависимостей) | Генерирует `năm mươi nghìn` из `50000` и настраивается на выговор: `nghìn/ngàn`, `lẻ/linh`, `tư/bốn`. Это и контент раздела «Цифры», и свёртка «цифры ↔ слова» в матчере, если замер покажет цифры |
| Туннель | npm-пакет `cloudflared` | Скачивает бинарник при `npm install`, ставить в систему ничего не надо |
| Снимки интерфейса | Playwright, эмуляция iPhone | Вёрстку и заглушку распознавания проверяем на столе. Само распознавание — только на живом телефоне |
| Тон слога | Свой разбор по NFD, без библиотеки | Пять знаков тона — двадцать строк. Готовых TS-пакетов, которые различают тон и сравнивают `hoà` с `hòa`, нет |

## Главный риск: vi-VN ни разу не измерен

Все журналы Speller сняты на английском. Правила «решаем по interim», «хвост
дописывается», «одна альтернатива, confidence 0.00» проверены только для
`en-US`. Для вьетнамского неизвестно ничего, а от ответов зависит, какие
упражнения вообще возможны. **Поэтому этап 0 — замер, и до него код уроков
не пишем.**

## Этапы

### 0. Замер распознавания vi-VN на устройствах

Копия `research/mic-probe.html` из Speller с `lang = 'vi-VN'` и протокол
`research/VI-PROBE-CHECKLIST.md`. iPhone с иконки домашнего экрана и Android
Chrome, оба по https через туннель.

Что выясняем, и что решает каждый ответ:

| Вопрос | Если «да» | Если «нет» |
|---|---|---|
| Interim приходит так же быстро (0.2–0.4 с)? | Проверка по interim, как в Speller | Упражнения ждут финала, и в UI появляется явное «слушаю…» |
| Распознаватель возвращает диакритику? | Можно сравнивать с тонами | Тон по распознаванию не проверить, только упражнения на слух |
| Неверный тон даёт другое слово (`ma` вместо `má`)? | Подсказка «слово верно, тон другой» | Языковая модель движка «исправляет» тон молча. Это честно пишем в README: тон проверяет только ухо |
| Одиночный слог распознаётся? | Алфавит и тоны тренируются голосом | Алфавит голосом только в составе слова, отдельные звуки — на слух |
| Числа приходят цифрами (`50 nghìn`, `50.000`)? | Нормализация «цифры ↔ слова» в профиле `vi` | Числа сравниваются как слова |
| Короткая фраза из 3–6 слогов целиком? | Упражнение «скажи фразу» | Фраза проверяется по частям |

Итог — `research/VI-PROBE-RESULTS.md` и правки в `CLAUDE.md`: факты из замера
становятся ограничениями, как в Speller.

**Этап закрыт 18.10.2026.** Измерено на iPhone (iOS 27, Safari): vi-VN
распознаётся и возвращает тоны; слушать можно только по касанию — сессия
без касания глухая; сессия сама закрывается через ~60 с. Остальное не
домеряли сознательно — замер стоил владельцу больше, чем ответы. Решения
без замера выбраны так, чтобы работать при любом ответе:

| Вопрос | Решение |
|---|---|
| Interim или финал | Засчитываем по interim, как в Speller: он пришёл сразу. Финал — запасной путь |
| Как слушать | Короткая сессия на шаг урока, по кнопке «говори». Никакого автозапуска после образца |
| Неверный тон — «почти» | Не показываем: не измерено, исправляет ли движок тон. Тон тренируем на слух |
| Одиночный слог | Алфавит и тоны — упражнения на слух; голосом — слова и фразы |
| Числа цифрами | Матчер сводит цифры и слова в обе стороны (`read-vietnamese-number`) — работает при любом ответе |
| Фраза целиком | Упражнение «скажи фразу»: окно матчера покрывает фразы до 8 слогов |

Недомеренное (тон, слоги) можно добрать позже из журнала самого
приложения, без отдельных прогонов.

### 1. Каркас

- Монорепо на npm workspaces:
  ```
  apps/web          Vite + TS + Preact, PWA
  apps/api          NestJS + Prisma + SQLite
  packages/core     матчер, движок урока, планировщик повторений, правила ачивок —
                    без DOM и без Nest, тестируется Vitest
  packages/content  алфавит, цифры, слова, фразы, темы, ачивки + проверочные тесты
  scripts/          ассеты, озвучка, сравнение голосов
  research/         пробы на устройствах и их журналы
  ```
- Из Speller переезжают: `matcher.ts` (профиль `vi`), `recognizer.ts`
  (один захват микрофона за сессию, авторестарт как страховка,
  `recognitionBlocker()`), `sound.ts` (громкость через `GainNode`, старт из
  касания), `motion.ts` (одна кривая), `tokens.css`, `base.css`, стенд
  `design-system.html`, `fetch-assets.mjs`, заставка `#boot`.
- PWA: манифест, иконки, service worker (`vite-plugin-pwa`). Оболочка, аудио
  пройденных уроков и разговорник кешируются. Распознаванию нужна сеть, это
  показывается явно.
- Тесты гоняются на каждый коммит: `npm test` по всем пакетам.

### 2. Озвучка

- `scripts/tts.mjs`: текст → mp3 по хешу «текст + голос + скорость». Повторный
  запуск ничего не перегенерирует. Для каждой фразы два файла: обычный и
  медленный (как «черепаха» у Falou).
- Движки: edge-tts (`vi-VN-HoaiMyNeural`, `vi-VN-NamMinhNeural`) и ElevenLabs
  (модель с поддержкой вьетнамского проверить синтезом: у ключа урезаны права,
  `/v1/models` отвечает 401, ключ при этом рабочий). Учёт квоты ElevenLabs
  локальным файлом, как в `youtube_shorts/src/shorts/tts/usage.py`.
- **Слепое прослушивание**: 30 фраз в двух-трёх голосах, страница
  `research/voice-compare.html`, семья голосует, не зная, где какой движок.
  Так же было устроено сравнение ударений в `remotion-skill`. Побеждает голос,
  а не движок.
- Ключи только в `.env`, в репозитории `.env.example`.

### 3. Модель контента и первые разделы

- Единица — **элемент**: слово или фраза. Поля: `id`, `vi`, `ru`, `alt`
  (засчитывается наравне), `dialect` (варианты Юга/Севера/Центра), `note`
  (короткое «почему так», заранее написанное, а не генерируемое), `icon`
  (необязательна, из Streamline), аудио.
- **Тесты контента** — главная защита от ошибок:
  - каждое слово фразы введено в этом или более раннем уроке;
  - нет пары элементов, которые после свёртки тонов становятся неразличимы
    в одном упражнении на выбор (`ma` / `má` в одном вопросе — только
    в тренировке тонов);
  - у каждого элемента есть аудио;
  - окно матчера не короче самой длинной фразы (правило из Speller).
- Первые разделы:
  1. **Алфавит и звуки.** 29 букв, сочетания (`ng`, `nh`, `ph`, `tr`, `gi`),
     что читается не так, как кажется русскому. Голосом или на слух,
     решает этап 0.
  2. **Тоны.** Шесть тонов на одном слоге, знаки, различение на слух.
  3. **Цифры.** 0–10, 11–99 (`mười một`, `hai mươi`, `mốt`, `lăm`), сотни,
     тысячи, миллионы — и как на самом деле говорят цены: `năm mươi nghìn`,
     `năm chục`, `50k`. В ценах ошибаются чаще всего, а слышат их каждый день.

Транскрипции кириллицей нет. Русские буквы не передают ни тон, ни половину
гласных, и «кам он» вместо `cảm ơn` закрепляется навсегда. Вместо неё —
медленная озвучка и разбор звука в разделе алфавита.

### 4. Движок урока (механика Falou)

Урок длится 3–5 минут, это 10–15 шагов. Типы шагов:

| Шаг | Что делает человек | Нужен микрофон |
|---|---|---|
| Послушай и повтори | слышит фразу, повторяет, видит, что засчитано | да |
| Скажи по-вьетнамски | видит русский, говорит сам | да |
| Что ты услышал | звук → один из 4 вариантов | нет |
| Собери фразу | плитки слов в правильном порядке | нет |
| Мини-диалог | сценка, реплики собеседника звучат, свои человек говорит | да |
| Тон на слух | какой из шести | нет |

- **Режим «не могу говорить»** на 15 минут, как у Duolingo: шаги с микрофоном
  меняются на шаги без него. В автобусе и в очереди к врачу этот режим нужен
  каждый день.
- У каждого шага предусмотрены все виды: слушаю, засчитано, почти (тон или
  одно слово), не засчитано с повтором образца, нет сети, нет разрешения на
  микрофон. Ни одно состояние не остаётся без вида.
- Движок урока лежит в `packages/core` и работает на событиях: интерфейс
  только показывает состояние.

### 5. Уровни и повторение

- **Уровни темы**, их четыре: «Узнаю» (на слух и выбор) → «Повторяю» (за
  голосом) → «Говорю сам» (с русского, в предложениях) → «Свободно» (без
  подсказок и медленной озвучки). Следующая тема открывается после первого
  уровня предыдущей, уходить вглубь можно потом.
- **Повторение**: каждый элемент — карточка FSRS. Ежедневная «Тренировка»
  собирается из карточек, у которых подошёл срок. Ошибка в уроке ставит
  карточку в очередь раньше.
- **Ежедневная цель** (5 / 10 / 20 минут) и серия дней.

### 6. Бэкенд NestJS

- Модули: `AuthModule` (логин и пароль, argon2, JWT в httpOnly-cookie),
  `FamilyModule` (семья и вход по коду-приглашению), `ProgressModule`,
  `AchievementsModule`, `LeaderboardModule`, `HealthModule` (`/health` для
  проверки контейнера).
- **Прогресс local-first**: клиент пишет события (`шаг пройден`, `урок
  закончен`, `карточка повторена`) в IndexedDB и досылает их пачкой на
  `POST /sync`. У события есть UUID, поэтому повторная отправка ничего не
  удваивает. Состояние FSRS и ачивки сервер пересчитывает из событий тем же
  кодом из `packages/core`, что и клиент. Это защищает от расхождения
  «на телефоне одно, в рейтинге другое».
- Nest раздаёт и собранный фронтенд (`ServeStaticModule`): один контейнер,
  один домен, cookie без CORS.
- Валидация — DTO с `class-validator`, документация — Swagger на `/api/docs`.
- `apps/api/NEST-NOTES.md` — учебные заметки: какой механизм Nest (модуль,
  провайдер, guard, pipe, interceptor) где у нас используется и почему.

### 7. Темы

Путь по темам. Внутри темы 4–6 уроков, в каждом уроке 6–10 новых элементов.
Порядок выбран по нужности на первой неделе в Дананге:

**A. Основы:** алфавит и звуки · тоны · цифры 0–99 · вежливость и обращения
(`anh / chị / em / cô / chú` — без них любая фраза звучит грубо) · деньги
и цены · я и семья.

**B. Город:** рынок (фрукты, овощи, вес, сколько стоит, дорого, торг) · кафе
и уличная еда (`cà phê sữa đá`, `không cay`, «без льда») · Grab и такси
(адрес, налево/направо, остановите здесь) · время, дни, часы.

**C. Быт:** квартира и аренда (хозяин, счёт за свет и воду) · ремонт
(не работает кондиционер, течёт, когда придёт мастер) · доставка и магазин ·
прачечная и парикмахерская.

**D. Учреждения:** врач и запись на приём (болит, температура, на какое
время) · аптека · банк (счёт, перевод, карта, банкомат) · регистрация
проживания.

**E. Досуг:** пиклбол (бронь корта, счёт, подача, «твой мяч») · пляж и море ·
знакомство и разговор ни о чём.

**F. Говор Центра** — только понимание на слух: `mô` (где), `tê` (там),
`răng` (почему, как), `rứa` (так), `ni` (это). Произносить их не учим,
образца голосом нет.

Контент заводится волнами, по теме за раз, и каждая волна проходит тесты
этапа 3.

### 8. Ачивки и семья

- Определения ачивок лежат в `packages/content`, проверка — чистая функция
  из `packages/core` над журналом событий. Сервер и клиент считают одинаково,
  каждое правило покрыто тестом.
- Виды: серии дней (3, 7, 30, 100) · тема пройдена на уровень · урок без
  ошибок · N слов в повторении · первая сказанная целиком фраза из диалога ·
  «ни одного дня без тренировки за неделю» · семейные (общая цель недели
  выполнена, вся семья позанималась в один день).
- Семейный рейтинг за неделю по минутам практики, а не по очкам: очки
  выгоднее набирать лёгкими уроками, минуты — нет.
- Иконки ачивок из того же стиля Streamline, эмодзи не используются нигде.

### 9. Разговорник «показать»

- Каждый пройденный элемент попадает в разговорник своей темы.
- Режим показа: фраза на весь экран крупным шрифтом, озвучка в полную
  громкость, русский мелко внизу. Экран повёрнут к собеседнику.
- Работает без сети: тексты и аудио в кеше service worker. Это единственная
  часть приложения, которой сеть не нужна, и интерфейс это говорит.
- Избранное и поиск по-русски.

### 10. Выкатка

- По скиллу `vps-ops`: приложение `viet-speller` на том же VPS, тип `web` (контейнер
  с Nest, `mem_limit`, `/health`), база в `data/`.
- Домен `viet-speller.p1gog.duckdns.org`: под-поддомен резолвится сам, сертификат
  выпускает Caddy. HTTPS обязателен для микрофона.
- Сборка образа на сервере, `vps deploy viet-speller`.

### 11. (По желанию) ИИ-собеседник на бесплатном тарифе

- Ролевой диалог голосом («продавщица на рынке», «администратор клиники»)
  через бесплатный тариф LLM. Gemini API или Groq — ключи у владельца уже
  есть. Модель держится лексики, которую человек уже прошёл.
- Ограничения честно: лимит запросов в минуту (Gemini free упирается в него
  быстро), данные бесплатного тарифа провайдер может использовать для
  обучения. Кончился лимит — у этого состояния есть свой вид («собеседник
  отдыхает до завтра»), а не зависание.
- Ключ только на сервере, запросы идут через Nest.
- Если бесплатного варианта к этому моменту не окажется — этап не делаем.

- Вибрацию: измерено в Speller, закрыто на обоих движках (см. `CLAUDE.md`).
- Транскрипцию кириллицей.
- Платные API.
